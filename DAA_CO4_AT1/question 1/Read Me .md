\# Minimum Spanning Tree using Prim's Algorithm



\## Aim

To find the Minimum Spanning Tree of a weighted graph using Prim's Algorithm.



\## Input Graph



0 2 3

2 0 1

3 1 0



\## MST Edges



0 - 1 : 2



1 - 2 : 1



\## Total Cost



3



\## Time Complexity



O(V²)



\## Space Complexity



O(V)



\## Conclusion



Prim's Algorithm successfully constructs the MST by repeatedly selecting the minimum-weight edge connecting a visited and unvisited vertex.
