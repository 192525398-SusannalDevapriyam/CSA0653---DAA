\# Minimum Spanning Tree using Kruskal's Algorithm



\## Aim

To find the Minimum Spanning Tree using Kruskal's Algorithm.



\## Input Edges



(0,1,2)



(0,2,3)



(1,2,1)



(1,3,4)



(2,3,5)



\## MST Edges



1 - 2 : 1



0 - 1 : 2



1 - 3 : 4



\## Total Cost



7



\## Time Complexity



O(E log E)



\## Space Complexity



O(V)



\## Conclusion



Kruskal's Algorithm constructs the MST by selecting edges in increasing order of weight while avoiding cycles.
