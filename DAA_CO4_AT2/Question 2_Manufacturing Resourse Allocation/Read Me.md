\# Manufacturing Resource Allocation using Dynamic Programming



\## Aim



To maximize profit within a production budget using Dynamic Programming.



\## Problem Type



0/1 Knapsack Optimization Problem



\## Budget



Rs. 100000



\## Product Details



| Product | Investment | Profit |

|---------|------------|--------|

| A       | 20000      | 25000  |

| B       | 30000      | 40000  |

| C       | 40000      | 50000  |

| D       | 50000      | 65000  |



\## Optimal Selection



A, B and D



\## Maximum Profit



Rs. 130000



\## Time Complexity



O(nW)



\## Space Complexity



O(nW)



\## Conclusion



Dynamic Programming efficiently finds the optimal product combination that maximizes profit without exceeding the available budget.
